# 构建与实机检查

## 导出包检查

1. `python3 tools/verify-export.py`：校验源码和包内容，检查相对路径和导出边界。
2. `python3 tools/check-patches.py /path/to/aosp`：只读检查补丁与目标分支是否匹配；不会应用补丁。默认检查01–06，`--without-sidebar`略过06。07在05已实际应用后单独检查。
3. `python3 tools/run-gesture-tests.py`：JDK21或更新，编译当前包内三个算法源和原有8个测试源。输出算法测试结果，不访问Android或手机。

`EXPORT_VALIDATION.json`只记录本次导出检查，不能把它当作其他设备通过验证。

## 编译范围

用目标项目的lunch／构建命令。核心、JNI、native输入／SF、WM Shell／SystemUI和Quickstep都需重建；模块名、分区及框架API规则以目标树为准。不要跳过API、AIDL、SELinux或native测试。此包不含签名密钥，不提供通用刷机命令。

已有Android测试源位于source里的coretests、wmtests和native tests/aura；Soong test模块和目标测试命令需在目标分支核对。纯JDK测试只覆盖协议、手势状态和几何，不能代替真实Surface／输入／动画测试。

## 最小实机矩阵

| 场景 | 关注点 |
| --- | --- |
| 关闭ro.aura.small_window | 原有全屏、多窗、PiP行为与输入不回归 |
| 首次开窗、竖／横屏桌面入口 | 画布比例正确，遮罩及时，三点／底条首帧出现 |
| 多入口替换小窗 | 旧窗动画退后台后新窗出现，不变大、不force-stop |
| 内容按钮、列表、编辑器、弹窗 | 缩放后坐标准确，透明装饰不拦内容 |
| 圆角内／外点击和下角缩放 | 外热区可调大小，圆角外无遮挡内容可用，安全遮挡策略不放宽 |
| 三点拖动与菜单 | 点击不误拖，拖动不误开菜单；装饰仅按钮／横条／角部拦触摸 |
| 底条上下滑、横滑、多指、CANCEL | 跟手预览、阈值提交，取消还原，不遗留所有权 |
| 最小化／恢复／双击全屏 | 比例与内容不拉伸，迷你不操作应用内部UI |
| IME显示隐藏、动画中拖动、浮动键盘 | 抬窗回位准确，多次操作不跳动、不争写Surface |
| 默认横屏游戏、视频横屏／退出播放器 | 仅小窗画布旋转，应用不误判禁止全屏，内容按钮点击准确 |
| 回桌面、打开应用、最近任务 | 自动最小化协调，桌面目标图标正确，不全局重排掉帧 |
| 系统中断、锁屏、旋转、任务退出 | 输入监视器和ViewHost释放，无system_server／SystemUI崩溃 |
| 快速返回与长返回侧边栏 | 快速返回不误触，应用名称完整，选择器按当前用户处理 |
| 密度／分辨率／不同屏幕宽度 | dp正确，几何安全限位，非默认显示器保持原生行为 |

最后用物理触摸和FrameTimeline确认全屏应用、桌面和小窗流畅度；显示模式的Hz数不等于没有帧队列延迟。不将本包之外的Aura刷新率／调度实验混入这轮验证。
